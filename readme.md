# Overview

"Hello World" application in C# to familiarize myself with the .NET ecosystem, the C# syntax, and the overall workflow of creating, running, and version-controlling a console application.

[Software Demo Video](https://youtu.be/your-video-id-here)

# Development Environment

- **Visual Studio Code** – used as the primary code editor with the C# Dev Kit extension for syntax highlighting, IntelliSense, and debugging support.
- **.NET SDK (version 10.0)** – used to create, build, and run the console application via the `dotnet` command-line interface.
